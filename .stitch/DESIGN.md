# WanderViet Design System - Traveloka DNA

## Brand Identity
- Primary: #0064D2 (Traveloka Blue) - headers, links, primary actions
- Secondary: #FF6D00 (Orange CTA) - call-to-action buttons, highlights, urgency
- Tertiary: #00A86B (Trust Green) - success states, verified badges, ratings
- Background: #F5F5F5 (Light gray surface)
- Surface: #FFFFFF (Cards, modals)

## Typography
- Font: Inter (clean, modern, highly readable)
- Headlines: Bold, tight letter-spacing
- Body: Regular weight, comfortable line-height
- Prices: Bold, larger size with orange/blue accent

## Card Design
- White background with subtle shadow (0 1px 4px rgba(0,0,0,0.08))
- 8px border radius
- Hover: elevated shadow (0 4px 16px rgba(0,0,0,0.12))
- Image aspect ratio: 16:9 for banners, 4:3 for cards

## Layout Principles
- Max width: 1200px centered
- Grid: 12-column on desktop, 2-column on mobile
- Spacing scale: 4px base unit (4, 8, 12, 16, 24, 32, 48)
- Section padding: 24px vertical on mobile, 48px on desktop

## Navigation
- Sticky header with white background and bottom shadow
- Blue logo on left, search center, user actions right
- Service tabs below header (icon + label)

## Interaction Patterns
- Buttons: Rounded 8px, bold text, clear hover states
- Primary CTA: Orange background, white text
- Secondary: Blue outline or blue text
- Cards: Entire card clickable, subtle scale on hover

## Travel-specific Patterns
- Search bar: White card with labeled fields, prominent search button
- Price display: Sale price in bold blue/orange, original price strikethrough
- Rating: Star icon + number, green/blue badge
- Flash sale: Countdown timer, red urgency badges
- Promo banners: Full-width carousel with gradient overlays
